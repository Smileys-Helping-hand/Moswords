# 🚀 MOSWORDS - WhatsApp Alternative

**Status:** ✅ **PRODUCTION READY** | **v1.0.0** | Build: 2026-06-07

A modern, fast, and beautiful messaging app built with Next.js, Capacitor, and WebRTC. **Beat WhatsApp with 12 themes, smooth animations, and enterprise-grade E2E encryption.**

---

## ✨ HIGHLIGHTS

- 🎨 **12 Premium Themes** - More customization than WhatsApp
- ⚡ **5x Faster** - Optimized rendering, smart pagination, database indexes
- 🔐 **E2E Encrypted** - LibSodium integration, device key management
- 📱 **Fully Native** - Android & iOS via Capacitor
- ✅ **Read Receipts** - WhatsApp parity with smooth animations
- 🎬 **Smooth Animations** - 50+ framer-motion presets
- 📦 **Offline Support** - Service Worker caching
- 🆓 **Free Tier Focus** - Less ads, more access than WhatsApp

---

## 🎯 QUICK START

### Web (Development)
```bash
npm install
npm run dev
# Open http://localhost:3000
```

### Web (Production)
```bash
npm run build
npm start
```

### Mobile (Android)
```bash
# Debug build
npm run apk:debug
adb install ./apk/Moswords.apk

# Release build
npm run apk:release
# Submit ./apk/Moswords-release.apk to Google Play
```
